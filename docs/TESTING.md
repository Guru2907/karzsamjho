# TESTING.md: how we prove it works

The number that matters most is K: wrong numbers shown as verified. K must be 0. "Couldn't verify" is a safe miss; a confident wrong rupee number is not.

## Unit tests (pytest, in api/tests/)
- test_maths.py: 12 cases: normal; fee upfront; EMI; in_hand missing (derive); repay missing; tenure 0; tenure missing; contradicting numbers; rounding; 30-day boundary; very small loan; large loan.
- test_verdict.py: each band boundary (35.9, 36, 100, 100.1), fee-upfront short loan, CANNOT_SAY.
- test_lender.py: exact name FOUND, near-miss SIMILAR, made-up NOT_FOUND, empty name.
- test_harass.py: the 10 samples below with their expected rules.
- test_evidence.py: hash chain verifies; editing one event breaks verify; 12-digit number masked.
Expected answers are written by people from the test data, never generated by the agent.
