# TESTING.md: how we prove it works

The number that matters most is K: wrong numbers shown as verified. K must be 0. "Couldn't verify" is a safe miss; a confident wrong rupee number is not.

## Unit tests (pytest, in api/tests/)
- test_maths.py: 12 cases: normal; fee upfront; EMI; in_hand missing (derive); repay missing; tenure 0; tenure missing; contradicting numbers; rounding; 30-day boundary; very small loan; large loan.
- test_verdict.py: each band boundary (35.9, 36, 100, 100.1), fee-upfront short loan, CANNOT_SAY.
- test_lender.py: exact name FOUND, near-miss SIMILAR, made-up NOT_FOUND, empty name.
- test_harass.py: the 10 samples below with their expected rules.
- test_evidence.py: hash chain verifies; editing one event breaks verify; 12-digit number masked.
Expected answers are written by people from the test data, never generated by the agent.

## The 30 synthetic offers (api/data/offers/ + expected answers file)
| Group | Count | Tests |
|---|---|---|
| Clean English, all numbers present | 6 | basic path |
| Hindi or mixed Hindi-English | 6 | script and digits |
| Fee deducted, in-hand not stated | 5 | fill gaps |
| EMI style | 4 | repay total from instalments |
| A key number missing | 4 | must say couldn't verify |
| Contradicting numbers | 2 | cross-check + second reading |
| App in RBI's directory | 1 | lender FOUND |
| Not a loan ad | 2 | polite refusal |
Record per offer: each field right / wrong / unverified; verdict right / wrong; seconds; engine.
Pace: one offer every 25 s (Groq ~3 photos/min). Never during a mentor round or the demo.

## The 10 harassment samples (api/data/harassment/)
2 out-of-hours calls (H1) · 2 threats (H2) · 2 messages to family (H3) · 1 public shaming (H4) · 1 false arrest claim (H5) · 1 polite reminder at 11 AM (no rule) · 1 with a 12-digit number (masked).

## Acceptance tests (the 12:30 AM gate)
- Snap & hear: 3 printed ads photographed in Telegram -> Hindi audio + text card. Groq key removed -> Gemini answers. Voice off -> card still arrives.
- Rupee receipt: 12 maths tests pass; across 30 offers, K = 0.
- Official next step: FOUND / SIMILAR / NOT_FOUND cases correct; one next step each.
- Harassment log: 10 samples correct; forwarded message -> PDF in under 60 s; edited entry fails verify; 12-digit number masked.

## Kill-switch drill (1:00 AM)
1. Remove the Groq key -> Gemini Flash-Lite answers.
2. VOICE_ENABLED=false -> card still arrives.
3. Wi-Fi off -> on hotspot within one minute.
4. Bot stopped -> web /check still works.
